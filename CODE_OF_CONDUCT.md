# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep discussion about the work, and do not harass anyone.
Unacceptable behaviour can be reported privately by opening a
[security advisory](https://github.com/Nithinfgs/shakeout/security/advisories/new) or by contacting
the maintainer through their GitHub profile. Maintainers may remove comments, issues or contributors
that violate these expectations.
